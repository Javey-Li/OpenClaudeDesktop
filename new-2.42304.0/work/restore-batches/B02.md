## Instructions
COMPACT.
1) projection.js:
- When compaction/start arrives and there is no inProgress turn, open a synthetic turn {dsh:null, id:`turn-c${data.compactionId}`, items:[], status:'inProgress', error:null, startedAtMs:time, completedAtMs:null, synthetic:true}.
  - Set this.current to it, push it to this.turns, and emit turn/started.
  - Then push the contextCompaction item (item/started) and record it in this.compactions.
- On compaction/end for a synthetic turn: emit item/completed, then close the turn and emit turn/completed.
  - Read the compaction/end payload type in harness/node_modules/@deepseek-ai/dsh-compaction/lib/types to detect failure or abort.
  - Map failure → 'failed' with error {message,…}, abort → 'interrupted', else 'completed'.
- Keep the existing in-turn behaviour.
- Expose `this.lastSyntheticCompactionTurnId` and a method `closeSynthetic(turnId, status, error)` that returns the turn/completed note when that turn is still inProgress (otherwise []).
- Replay must produce the same synthetic turn.

2) New compact.js:
- Signature: `export async function runCompact({execute, signal, threadId, notify, openedTurnId, closeOpened, newTurnId})`.
- `execute(signal)` resolves to a dsh-commands CommandExecution {commandId, result:{kind,text}} or undefined. NOTE: the result is nested under `.result`.
- Outcome:
  - signal.aborted → 'interrupted';
  - throw, undefined, or result.kind==='error' → 'failed' with message = result.text or errorChain(error);
  - otherwise 'completed'.
- If openedTurnId() returns an id: for 'completed', do nothing (the projector already emitted the lifecycle); otherwise notify the notes from closeOpened(id, status, error).
- If no turn was opened (nothing to compact, or failed before start): synthesize id = newTurnId() (`turn-compact-<uuid>`), notify turn/started {threadId, turn:{id, items:[], itemsView:'notLoaded', status:'inProgress', error:null, startedAt, completedAt:null, durationMs:null}}, then notify turn/completed with the final status. The error is {message, codexErrorInfo:null, additionalDetails:null, misalignment:null} when failed.

3) index.js thread/compact/start:
- After openThread, throw RpcError(-32600, 'Wait for the current turn to finish before compacting.', {codexErrorInfo:'activeTurnNotSteerable'}) if thread.agent.status==='running', thread.projector.activeTurn, or thread.compaction is set.
- Set thread.compaction = {controller: new AbortController(), startedTurn: projector.lastSyntheticCompactionTurnId} and publishStatus.
- Start runCompact without awaiting it, with execute = (signal) => commands.execute(thread.agent, '/compact', [], signal).
- openedTurnId returns projector.lastSyntheticCompactionTurnId when it differs from startedTurn.
- In finally: clear thread.compaction and publishStatus.
- Return {}.
- LiveThread.status() reports active while thread.compaction is set.
- turn/interrupt also aborts thread.compaction?.controller.

QUEUE.
4) Read the exact shapes first: analysis/codex-protocol/v2/ThreadQueue*Params/Response.ts and QueuedSubmission.ts, plus the comment at app/electron/main.cjs:101-110 (queuedSubmissionId, queuedSubmissionIds, clientUserMessageId).
- New pure queue.js:
  - toQueuedSubmission(message, remembered) → {id: message.id, input: remembered?.input ?? userInputsOf(message), clientUserMessageId: remembered?.clientUserMessageId ?? null};
  - reorderedMessages(nextTurn, ids): throw invalidParams unless ids is a permutation of the nextTurn ids, then return the messages in that order.

5) index.js:
- LiveThread.queued = new Map() (message id → {input, clientUserMessageId}).
- thread/queue/add: openThread, msg = inputMessage(params.input), remember it, thread.agent.followup(msg), notify thread/queue/changed {threadId}, and return the protocol response containing toQueuedSubmission.
- thread/queue/list: if the thread is live, map agent.inbox.nextTurn; otherwise return {data:[], nextCursor:null}. Remove 'thread/queue/list' from the empty-list case group at :718.
- delete: inbox.remove(id); throw invalidParams('That queued message already started.') if it returns false.
- update: replacement = inputMessage(input); inbox.replace(id, replacement); move the remembered entry to replacement.id.
- reorder: inbox.splice('next-turn', 0, nextTurn.length, reorderedMessages(...)).
- start: if the agent is running, remove the entry and agent.steer(msg); otherwise it is a no-op (followup already woke the driver).
- Each mutation notifies thread/queue/changed.
- Subscribe ctx.on('agent/inbox/inserted' | 'agent/inbox/claimed' | 'agent/inbox/discarded', ({agent}) => byAgent(agent) && notify('thread/queue/changed', {threadId})). The payload carries .agent per dsh-agent runtime-types.d.ts:263-292.
- turn/interrupt: keep = agent.inbox.nextTurn.length > 0; call agent.cancel({kind:'user'}, {keepInbox: keep}). When keep is true, also clear steering with inbox.splice('next-step', 0, inbox.nextStep.length, []), so stopped steer text does not start a turn.

6) README: remove thread/queue/* from 未实现, and describe compaction as a synthetic `turn-c…` turn.

APP RPC ERROR PASSTHROUGH.
7) Electron's ipcRenderer.invoke drops error.data.
- In app/electron/main.cjs case 'rpc', wrap only the final client.request call. On an error with a numeric `code` (a JSON-RPC error from the core), RETURN {__codeDesktopRpcError:{message, code, data}} instead of throwing. Allowlist and validation errors still throw.
- New app/src/rpc-error.mjs exports rpcResult(value): when value?.__codeDesktopRpcError exists, it throws an Error with that message plus .code and .data; otherwise it returns value.
- Change `const rpc` in main.jsx:131 to `(m,p) => call('rpc',{method:m,params:p}).then(rpcResult)`.
- grep app/src for other `call("rpc"` or `call('rpc'` sites (popout, hooks, stores) and route them through rpcResult too.
- queued-messages-model.isNotSteerable then sees data.codexErrorInfo, so the steer→queue fallback at main.jsx:1233 works. No change to the queue UI is needed.
