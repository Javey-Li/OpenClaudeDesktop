# Arc UI free components

These files are the free, MIT-licensed components from [Arc UI](https://uiarc.dev), copied from the public shadcn registry (`https://uiarc.dev/r/<name>.json`) on 2026-11-07:

- Badge
- Avatar
- Progress
- Usage meter
- Empty state
- Button
- Tooltip
- Segmented control

The shared motion presets and the optional Arc provider are included unchanged. Pro components are not included; the agent-specific patterns in the board are original work that follows the public previews.
