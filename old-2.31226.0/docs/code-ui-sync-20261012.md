3. **Deleted file tabs** — `cccc2cf0a-DHtZKTKW.js` `wb` reads cached `unavailable === "missing"`; the mapped tab carries `deleted`. `cfe7c4b3b-C2Lhkd1Y.js` applies line-through and a screen-reader deleted hint in both strip and overflow. Local file reads already distinguish missing from outside-root, binary, large and read errors. Only missing receives this treatment. Restoring and reopening the file clears the marker.

## Scope and remaining differences

These are targeted parity improvements, not a claim of complete Code parity with 2.31226.0. The current source gates some features (including close-right) behind rollout flags; this app enables the implemented close-right action. Third-party authenticated services are not replicated by these changes. Cowork VM/inference acceptance remains separate from Code UI verification.

Implemented behavior:
- Text is directly editable. Dirty files show Save / Cancel and become fixed tabs. Cmd+S, undo/redo, selections, line jumps and Find work in the actual editor.
- Saves use a byte hash from an editable read. An external change or deletion retains the draft and offers Override or Save anyway; an override compares against the latest reported hash, so a second external change conflicts again. Failed writes leave the existing file intact.
- The local write adapter validates the workspace and resolved path, serializes application saves, preserves file mode, and uses a same-directory temporary file followed by rename. - Dirty tab switches, tab/pane close, session navigation, pop-out and dock use the discard intent. Window reload/close and application quit also protect unsaved drafts. Quit checks happen before child-process shutdown.
- Empty files can be edited. Markdown retains the Preview/Source toggle, returning to updated rendered content after saving. Non-text artifact/media viewers keep their existing paths. Editing is limited to local, valid UTF-8, non-binary files at most 1 MiB; malformed UTF-8 remains read-only.
