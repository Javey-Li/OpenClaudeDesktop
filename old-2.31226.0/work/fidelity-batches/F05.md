- Unsent text and attachments survive session switches.
- The editor stays typeable while loading or disconnected.
- Mode, Model and Effort work during a turn.
- Escape anywhere stops a running turn.
- ↑ in an empty editor pulls back the last queued message.
- Skills appear in '/' as skill chips.
- @ file picks insert atomic mention chips.
- Slash-command notices are CDS toasts.
